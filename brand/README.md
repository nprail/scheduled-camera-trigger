# Kairos brand assets

Source of truth: the **Kairos** design system artifact (colors, type, logo rules). These files are copies for the apps.

| File | Use |
| --- | --- |
| `kairos-mark.svg` | Mark on `ground` / light surfaces |
| `kairos-mark-reversed.svg` | Mark on `ink` / dark surfaces |
| `kairos-mark-small.svg` | Below 32 px and the app icon (heavier strokes, no side ticks) |
| `fonts/SpaceGrotesk-Variable.ttf` | Display type: the `kairos` wordmark, headlines, titles |
| `fonts/JetBrainsMono-Variable.ttf` | Every time, duration and config value |

Both fonts are licensed under the SIL Open Font License 1.1 (see `fonts/OFL-*.txt`). The apps carry their own copies (`ios/Kairos/Fonts/`, `android/app/src/main/res/font/`).
